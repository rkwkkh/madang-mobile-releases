# Madang Android Releases

This repository contains public APK releases for the Madang garden planning app. The application source code is maintained in a separate private repository.

## Install or update

1. Open the [latest release](https://github.com/rkwkkh/madang-mobile-releases/releases/latest).
2. Download `app-release.apk`.
3. Open the downloaded APK and approve Android's installation prompt.

Android may ask you to allow APK installation from the browser or file manager. Updates must be signed with the same app key; install over the existing app to keep its local projects.

Madang is an early prototype. Back up important project data before installing test releases.
